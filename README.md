
# Kalkulačka ročních bonusů 2026

### Spočítejte si orientační roční odměnu!

Jednoduchá kalkulačka pro výpočet ročních bonusů a zaměstnaneckých odměn.

## Co aplikace nabízí?

- Orientační výpočet ročního bonusu
- Porovnání různých variant odměňování
- Rychlé a jednoduché použití
- Bez nutnosti registrace
- Možnost offline použití

## Stažení

Aktuální verzi aplikace naleznete v sekci **Releases**.

1. Otevřete sekci **Releases**.
2. Stáhněte nejnovější verzi aplikace.
3. Spusťte stažený soubor.

## Systémové požadavky

- Windows 10 / Windows 11
- Není nutná instalace dalších aplikací
- Internetové připojení není pro samotné spuštění vyžadováno
